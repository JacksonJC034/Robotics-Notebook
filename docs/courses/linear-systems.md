# Linear System Theory

How much can a robot infer from position measurements alone? Can one actuator bring both position and velocity to a chosen target? These EECS 560 / ME 564 notes develop the two questions together. A moving axis serves as a running example, from the state equations to a controller that estimates velocity from position.
