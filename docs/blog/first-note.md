# 把一次学习，变成可复用的知识

2026-11-04 · 学习方法 · 3 分钟阅读 · 示例文章

## 一个问题开始

知识库不必从完整目录开始。先写下今天遇到的具体问题：一个坐标变换为何方向相反，或者一次轨迹跟踪为何振荡。

## 三层记录

第一层保留问题与现象，第二层给出推导和最小代码，第三层写清验证结果。只记结论，很容易丢掉结论适用的条件。

## 一个可持续的节奏

每次学习结束，用几分钟记录“理解了什么、证据是什么、接下来验证什么”。每周把重复出现的概念整理进知识库，把过程留在博客里。
